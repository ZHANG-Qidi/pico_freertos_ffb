#+TITLE: FreeRTOS HID FFB Wheel Firmware

这是一个基于 FreeRTOS 的 USB HID 力反馈方向盘固件。设备向主机提供方向盘和三路踏板轴输入，并通过 HID PID（Physical Interface Device）报告接收游戏发送的力反馈效果。固件通过磁编码器获取方向盘位置，并使用 SimpleFOC 控制三相无刷电机。

#+begin_quote
本项目面向开发和实验。电机可能产生较大扭矩；首次上电、调参和测试时应卸载方向盘负载、准备独立急停，并从较低电压和力反馈增益开始。
#+end_quote

* 功能特性

- USB HID 游戏控制器，提供方向盘轴和三路踏板轴输入。
- HID PID 力反馈接口，管理最多 32 个效果块。
- 使用磁编码器反馈方向盘位置，并通过 FOC 控制三相无刷电机。
- 支持恒定力、阻尼及扩展阻尼效果，并处理设备总增益和单效果增益。
- 提供方向盘行程软件限位。
- 使用 FreeRTOS 管理 USB、FOC、模拟输入和状态指示等工作。

** 关键基础组件

| 组件 | 作用 |
|------+------|
| Arduino 兼容层 | 将平台的 GPIO、ADC、SPI、I²C、PWM 和时间服务等接口适配为 Arduino 风格 API，供 SimpleFOC 等上层代码调用。它负责平台硬件适配，不承载 HID 力反馈协议逻辑。 |
| TinyUSB | 提供 USB Device 协议栈，处理 USB 枚举、端点传输和 HID 类通信。项目在其基础上实现设备描述符、输入报告及 PID 力反馈报告的收发。 |
| HID-FFB | 实现方向盘和踏板的 HID 报告、PID 力反馈效果解析与计算，并将效果转换为电机控制目标。 |
| SimpleFOC | 执行三相无刷电机的 FOC 控制；通过 Arduino 兼容层访问底层传感器与驱动接口。 |
| FreeRTOS | 调度 USB、FOC、模拟输入采样和状态指示等并行工作。 |

** Arduino 兼容层

Arduino 兼容层为 SimpleFOC 和其他 Arduino 风格代码提供统一接口，并将 GPIO、总线、ADC、PWM 与时间服务等操作转接到当前平台的硬件实现。它是平台适配边界：上层 FOC/FFB 逻辑通过兼容接口访问外设，平台相关的引脚与外设映射则由对应工程配置。

** USB 与 HID-FFB

TinyUSB 负责 USB Device 协议栈和 HID 通信基础；HID-FFB 负责设备描述符、方向盘/踏板输入报告、PID 力反馈报告处理及效果计算。两者分工明确：TinyUSB 提供传输机制，HID-FFB 定义并实现本设备使用的 HID/FFB 行为。

* 配置入口

** =Arduino_config.h=：兼容层与硬件资源配置

此配置入口维护 Arduino 兼容层及外设使用的板级资源映射，例如 GPIO、UART、I²C、SPI、ADC 和电机驱动输出。更换接线或外设资源时，优先检查该文件及其平台对应的初始化配置。不要将平台引脚细节散落到 HID-FFB 或 FOC 逻辑中。

** =FFB_config.h=：电机、FOC 与力反馈设定

此配置入口维护与具体 GPIO 映射分离的设备和控制参数，例如电机极对数、传感器类型与方向、供电和电压限制、FOC 控制周期、方向盘行程、Commander 波特率，以及恒定力和阻尼增益。更换电机或传感器、调整控制和手感参数时，优先检查该文件；传感器实际接线与外设实例仍由板级配置负责。

* 力反馈支持情况

当前控制逻辑主要支持：

- 恒定力（Constant Force）。
- 阻尼（Damper）及扩展阻尼类型（=ET_DAMPER_DR2=）。
- 设备总增益和单效果增益。
- 最多 32 个效果块的分配、启停与释放。

HID 描述符可能声明其他 PID 效果类型，但弹簧、摩擦、惯性、周期波形、包络及部分设备控制行为尚未完整实现。因此，不同游戏和驱动软件的兼容性会有所差异。

* USB 身份与兼容性

当前实现使用 Logitech G923 Xbox 的 VID/PID 作为兼容性测试身份。该身份不代表本项目与 Logitech 存在关联，也不应直接用于自有产品发布；自定义硬件应使用合法分配的 VID/PID。

* 安全提示

电机电压、驱动器、电流能力、传感器方向和软件行程限制都会影响设备安全。更换电机、驱动器或传感器后，应重新核对参数和接线，不要直接沿用默认值运行。测试时使用独立急停，并从较低电压与力反馈增益开始。
